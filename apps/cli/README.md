# Densio

Densio is an agent-first CLI for video compression, image extraction, and
quality comparison through the Densio API.

Run it without a global installation:

```sh
npx densio --help
```

Use `npx densio capabilities --json` to inspect the server's current codecs,
limits, and defaults before creating media jobs.

See the [Densio repository](https://github.com/pixel-point/densio) for
authentication, media-command, self-hosting, and API documentation.
